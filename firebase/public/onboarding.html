7-Day New Player Experience

Document Version: 1.0 | Last Updated: January 31, 2026 | Purpose: Guide new players from download to core loop mastery

🎯 Design Philosophy

Goals:

  1. Teach core mechanics without overwhelming
  2. Create habit formation (daily return)
  3. Unlock viral features progressively
  4. Ensure accessibility from minute one
  5. Build emotional connection to the universe

Anti-Goals:

  • ❌ No manipulation or dark patterns
  • ❌ No forced social interaction
  • ❌ No overwhelming complexity
  • ❌ No punitive systems

🎓 Tutorial Approach

Principles:

  1. Show, don't tell: Visuals > text walls
  2. Interactivity first: Learn by doing
  3. Optional depth: Tooltips for curious players
  4. Accessibility always: Multiple learning modes
  5. Celebrate mistakes: "Oops!" moments are playful

Tutorial Delivery Methods:

Visual Guides:

  • Glowing highlights on interactive elements
  • Animated arrows (gentle, not intrusive)
  • Particle trails showing gesture paths

Audio Guides:

  • Soft chimes for correct actions
  • Gentle narration (optional, can disable)
  • Haptic feedback synchronized

Text Guides:

  • Plain language (6th grade reading level)
  • Short, digestible sentences
  • Always skippable

NPC Guides:

  • Fateweaver Orb (mystical but friendly)
  • Realm-specific sprites (Spark, etc.)
  • Never condescending, always encouraging

  • Simplify Day 1 flow

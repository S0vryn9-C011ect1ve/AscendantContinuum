Accessibility

The Ascendant Continuum — Accessibility IS Gameplay

The Ascendant Continuum is built on a simple belief: a calming, magical puzzle-adventure should be playable by everyone. Accessibility is not a bolt-on feature here — it is core to how the game feels. Below are the modes and commitments we build toward.

Visual Modes

  • Colorblind support — alternate palettes and symbol cues (not color alone) for realm distinction and puzzle state.
  • High-contrast mode — boosted contrast for players who need it, without losing the cosmic aesthetic.
  • Scalable text — UI text respects system font-size settings; nothing is locked to a tiny size.
  • Reduced-motion mode — particle and transition effects can be dialed down or off for players with vestibular sensitivity.

Input & Navigation

  • Full keyboard navigation for menus and non-timing-critical puzzles.
  • Touch targets sized for low-dexterity play; no precise-timing gates.
  • Session length of 1–5 minutes by design — friendly to fatigue, pain, and attention variability.

Our Commitment

We aim to meet WCAG 2.2 AA where the web build is concerned, and to treat cognitive load as a first-class design constraint. If something blocks you, we want to know.

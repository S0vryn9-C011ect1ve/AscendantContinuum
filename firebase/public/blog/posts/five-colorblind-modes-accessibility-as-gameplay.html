5 Colorblind Modes: Accessibility as Gameplay

"Different vision isn't a limitation—it's a different way to experience the universe. Here's how The Ascendant Continuum turns accessibility into discovery."

Development Note: This game is in early development. I'm a solo developer learning Unity while building this project. The features described here are implemented and working in the current build, but the game is not yet publicly released. I'm sharing technical details transparently as I build in public.

The Short Version

The Ascendant Continuum features 5 colorblind modes. But they're not just filters or accommodation options—each mode reveals completely different hidden content that other players can't see.

The 5 modes: Protanopia (red-blind), Deuteranopia (green-blind), Tritanopia (blue-blind), Achromatopsia (monochrome), and Protanomaly (weak red perception).

Why I Built This

I'm disabled. Workplace injury ended my healthcare career. When I started learning Unity to build my first game, I knew accessibility couldn't be an afterthought—it had to be foundational.

But instead of just making the game accessible, I asked: what if accessibility settings unlocked unique experiences? What if different ways of seeing revealed different secrets?

That question became the core innovation of this game.

The 5 Colorblind Modes (Technical Details)

Here are the actual modes implemented in the game's AccessibilityManager.cs system:

🔴 Protanopia

Red-blind (difficulty perceiving red)

What players with Protanopia see: Reduced red perception makes certain reds appear brownish or grayish. Reds and greens can be hard to distinguish.

Unique content revealed: "Crimson Veil" runes hidden in Emberforge flames. Objects tagged with ProtanopiaSecret become visible only in this mode. Fire-based sigils have special patterns that emerge when red perception is altered.

Game lore: The Crimson Veil mysteries are ancient fire secrets written in wavelengths that require different perception to detect.

🟢 Deuteranopia

Green-blind (difficulty perceiving green)

What players with Deuteranopia see: Reduced green perception. Greens appear more brownish or beige. Greens and reds are difficult to differentiate.

Unique content revealed: "Emerald Mysteries" lore fragments in Verdant Sanctuary. Growth-based secrets, plant patterns, and forest sigils that only appear when green perception shifts. Objects tagged DeuteranopiaSecret unlock.

Game lore: Ancient plant spirits encoded messages in chlorophyll patterns. Different vision reveals different botanical wisdom.

🔵 Tritanopia

Blue-blind (difficulty perceiving blue)

What players with Tritanopia see: Reduced blue perception. Blues appear greenish, and yellows appear pinkish. Blues and greens are harder to distinguish.

Unique content revealed: "Azure Pathways" in Echo Fields and Lantern Ascension. Sky-based navigation secrets, constellation patterns, and celestial sigils that emerge when blue perception changes. TritanopiaSecret objects become visible.

Game lore: The night sky holds paths written in starlight wavelengths. Tritanopia vision reveals celestial roads invisible to others.

⚫ Achromatopsia

Monochrome vision (complete colorblindness)

What players with Achromatopsia see: No color perception—only shades of gray. Vision relies entirely on brightness, contrast, and edges.

Unique content revealed: Edge-based sigil puzzles and monochrome hidden patterns. When color is removed, underlying geometric structures become visible. Sacred geometry puzzles that rely on shape rather than color. AchromatopsiaSecret objects reveal pure pattern-based mysteries.

Game lore: The universe's fundamental structure exists beyond color. Monochrome vision sees the universe's skeleton—its pure mathematical truth.

🔴🟤 Protanomaly

Weak red perception (partial red-blindness)

What players with Protanomaly see: Reduced sensitivity to red light. Not completely red-blind like Protanopia, but reds appear duller, more orange or brown. Red/green distinction is weakened.

Unique content revealed: "Ember Whispers"—subtle fire patterns and warm-spectrum secrets that exist in the boundary between red perception and absence. ProtanomalySecret objects unlock transitional mysteries about transformation and change.

Game lore: Some secrets exist in the liminal space—not fully hidden, not fully revealed. Protanomaly vision sees the in-between.

How It Actually Works (The Code)

I'm building this in Unity using C#. Here's how the system works technically:

1. The Accessibility Manager

The AccessibilityManager.cs script defines the colorblind modes as an enum: 

public enum ColorblindMode
{
    None = 0,
    Protanopia = 1,      // Red-blind
    Deuteranopia = 2,    // Green-blind
    Tritanopia = 3,      // Blue-blind
    Achromatopsia = 4,   // Monochrome
    Protanomaly = 5      // Weak red
}

2. The Secrets Manager

The AccessibilitySecretsManager.cs script manages which content is visible. It works using Unity's tag system:

  • Game objects in the world are tagged (e.g., "ProtanopiaSecret")
  • The manager polls the accessibility settings every frame
  • When colorblind mode changes, it rescans the scene
  • Objects are shown/hidden based on which mode is active

3. Color Transformation Shaders

Visual appearance changes using custom shaders that simulate each type of colorblindness. These aren't simple filters—they're color transformation matrices based on actual colorblindness simulation research.

4. Content Design

Each realm has objects specifically designed to be hidden unless you're using a particular accessibility mode:

  • Emberforge Peaks (fire realm): Crimson Veil runes for Protanopia players
  • Verdant Sanctuary (nature realm): Emerald Mysteries for Deuteranopia players
  • Echo Fields (memory realm): Azure Pathways for Tritanopia players
  • All realms: Sacred geometry for Achromatopsia players

Why This Matters

Traditional game accessibility:

"We added a colorblind mode so everyone can play the same game."

What I'm building:

"Different ways of seeing reveal different universes. Accessibility isn't accommodation—it's discovery."

The Philosophy

  1. No "default" experience: Every visual mode is equally valid and unique
  2. Accessibility as advantage: Players actively choose different modes to discover secrets
  3. Community collaboration: Players share what they found in their accessibility mode
  4. Replayability: You can switch modes anytime to see different content

Beyond Colorblind Modes

The system extends to other accessibility features too:

  • Screen Reader mode: Reveals audio-only secrets and NPC whisper dialogues
  • Reduced Motion mode: Unlocks "Timeless Realm" frozen-frame mysteries
  • Neurodivergent modes (ADHD, Autism, Dyslexia): Each reveals mode-specific bonus content

The Response

I recently posted about this system on social media and said "8 colorblind modes." That was wrong—I miscounted in the automation. It's 5 modes, not 8. I'm a solo developer learning as I go, and I made a mistake.

But the system itself? It's real. It works. And it's provable with code.

Some people were skeptical. I get it—claiming "accessibility as gameplay" sounds like marketing spin. But this blog post exists to show exactly how it works, with actual code, actual technical details, and honest transparency about the development stage.

## 💡 PRO TIPS

**Finding Perfect Ambient Music:**
1. Search "meditation" or "ambient" on Pixabay
2. Listen to 30-second preview
3. Download 3-5 candidates per realm
4. Test in game scene for "vibe match"
5. Keep best, delete rest

**Making SFX Fit Your Game:**
1. Most sounds are too loud/harsh initially
2. In Audacity: Effect → Normalize to -6 dB
3. Add slight fade in/out (0.05s) to prevent clicks
4. Export as WAV for Unity

**Reducing File Size:**
- Music: OGG Vorbis at 96-128 kbps (4-6 MB per 3-min track)
- SFX: Mono (not stereo) cuts size in half
- Sample rate: 22050 Hz vs 44100 Hz saves 50%
- Total audio budget: Aim for <50 MB all files

**Looping Music Seamlessly:**
1. In Audacity, check waveform start/end
2. Ensure end amplitude matches start
3. Use Effect → Crossfade Tracks if needed
4. In Unity, enable "Loop" on AudioSource

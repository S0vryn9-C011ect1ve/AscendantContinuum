## 🎭 Voice & Tone Guidelines

### Authentic Voice
- **Helpful, not preachy** - "Here's what worked for me" not "You should do this"
- **Learning journey** - "I discovered..." not "Everyone knows..."
- **Honest about limitations** - "I'm learning [X]" not "I'm an expert"
- **Enthusiastic, not arrogant** - Share excitement, acknowledge challenges
- **Specific, not vague** - Real examples, actual numbers, concrete details

### Avoid These Tones
- ❌ **Confrontational** - "Nobody explains this properly"
- ❌ **Expert/Authority** - "Most devs get this wrong"
- ❌ **Victim mentality** - "Everything is hard and unfair"
- ❌ **Bragging** - "Look how amazing I am"
- ❌ **Marketing speak** - Overhyped, vague promises

### Use These Tones
- ✅ **Collaborative** - "Here's what I learned..."
- ✅ **Curious** - "I wondered if... and discovered..."
- ✅ **Grateful** - "Thanks to [tool/resource], I could..."
- ✅ **Realistic** - "This takes time, but it's working"
- ✅ **Excited** - "Just got this working - here's how"

## 🎮 Game-Specific Facts

### The Ascendant Continuum
- **Genre:** Gamified meta-reality adventure, meditation/mindfulness game
- **Status:** Early development (not released, not RC, not beta)
- **Platform:** Unity, targeting WebGL + mobile (Android/iOS)
- **Current state:** Core systems implemented, building content

### Key Features (Real & Implemented)
- ✅ **5 realms** (Emberforge, Verdant Sanctuary, Echo Fields, Dawn Citadel, Lantern Ascension)
- ✅ **Accessibility as gameplay** - different modes reveal different secrets
- ✅ **5 colorblind modes** (Protanopia, Deuteranopia, Tritanopia, Achromatopsia, Protanomaly)
- ✅ **Moon phase integration** - real lunar data affects gameplay
- ✅ **NPC collective memory** - game characters (NPCs) remember what all players tell them
- ✅ **Procedural ritual generation** - algorithm-created challenges
- ✅ **Digital Sunset feature** - mindful play time management
- ✅ **1-5 minute sessions** - respecting player time

### Design Philosophy
- **Anti-addiction by design** - no FOMO, no dark patterns
- **Accessibility-first** - not an afterthought
- **Ethical monetization** - cosmetics only (planned)
- **Positive empowerment** - no fail states, no punishments
- **Respect player time** - short meaningful sessions

## 📝 Content Creation Checklist

Before publishing any blog post or social media content, verify:

### Accuracy
- [ ] No false budget claims (contractors, spending)
- [ ] Correct skill acknowledgment (artistic background)
- [ ] Accurate tool attribution (Copilot, free tools, courses)
- [ ] No fake player/tester/community references
- [ ] Game status accurate (in development, no players yet)
- [ ] Features claimed are actually implemented

### Voice
- [ ] First person ("I") not plural ("we")
- [ ] Helpful collaborative tone, not confrontational
- [ ] Learning journey framing, not expert authority
- [ ] Specific examples, not vague generalizations
- [ ] Enthusiastic but honest about challenges

### Technical Terms
- [ ] Gaming jargon explained for general public
- [ ] NPC → game character (NPC) on first use
- [ ] Unity → Unity (game engine) on first use
- [ ] FPS → FPS (frames per second) on first use
- [ ] Technical terms given context

### Tense
- [ ] Present tense for what exists now
- [ ] Future tense for player features ("Planning: players will...")
- [ ] Accurate timeframe (in development, not released)

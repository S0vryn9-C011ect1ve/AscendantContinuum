# Launch Resources

This document is the canonical destination for historical launch-prep, zero-budget production, and day-by-day implementation guidance during repository consolidation.

## Purpose

The repository previously stored multiple root-level launch roadmaps, audio sourcing guides, marketing guides, tutorial instructions, and day-session plans. Their useful content is consolidated here so the root no longer carries competing operational playbooks.

## Canonical Launch Themes

### Launch planning
- Launch sequencing should align with actual build readiness and current project status.
- Historical 6-week zero-budget roadmaps are reference material, not authoritative schedules.

### Audio sourcing and production
- Zero-budget sourcing guidance remains useful as a resource for free/legal audio sourcing.
- Active asset intake rules are governed by `docs/standards/asset-management.md`.
- Realm and UI audio should be placed under `Assets/_Project/Audio/` using canonical naming conventions.

### Marketing and positioning
- Historical zero-budget marketing guidance is preserved as a reference for messaging, outreach, and launch story framing.
- Current website/social/content policy should stay aligned with `docs/social/CONTENT_GOVERNANCE.md` and `docs/social/README.md`.

### Tutorial and onboarding implementation
- Tutorial/onboarding implementation guidance should align with `docs/operations/implementation-guides.md` and `docs/operations/unity-scene-prefab-workflows.md`.
- Do not create new root-level implementation guides for onboarding work.

### Daily work/session plans
- Historical daily work-session files are snapshots, not active sources of truth.
- Ongoing work should be tracked in canonical operations docs and issue/PR workflow, not ad hoc root markdown.
